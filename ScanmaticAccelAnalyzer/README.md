# Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Читает **нативный лог Scanmatik `.sm2`** (заголовок SMFS), OBD-II Livedata — с ПК и с телефона.

## Что делает

1. Загружает один или несколько `.sm2`.
2. Сам находит каналы **обороты**, **время**, **педаль или дроссель** (и скорость, если есть).
3. Собирает **все участки разгона на одной передаче**. Ползунки оборотов — окно, **сквозь которое** разгон должен пройти (например 4000–5000); на графике весь набор оборотов **от начала роста до конца**, без обрезки по ползункам.
4. Строит графики **полка Link / dRPM/dt / Dyno**, выравнивание по оборотам **2000–7500**.

Если в логе дроссель не доходит до 70%, порог подстраивается по максимуму канала. Если педали нет — ищутся короткие разгоны по росту оборотов.

## Запуск

`Запуск.bat` или открыть `index.html` в Chrome / Edge.

## Как писать лог в Сканматике

1. Модуль **OBD-II** → текущие данные (Livedata).
2. Включите:
   - обороты двигателя (PID 0x0C);
   - положение педали **или** абсолютное положение дросселя (PID 0x11 / 0x49 / 0x4A).
3. Сохраните `.sm2` и загрузите в приложение. Подойдёт и **CSV Сканматика** (колонки обороты + педаль/дроссель). Логи других программ не разбираются.

## Примеры (все — Scanmatik SMFS)

Педаль в пол на одной передаче (ПК, дроссель ≈ 86%):

- `sample/1.sm2` / `sample/2.sm2` — два WOT ~1746–5782 и ~1174–5784
- `sample/260917_1441_Двигатель_[7E8].sm2` — 4 разгона
- `sample/scanmatik_obd2.csv` — тот же ПК-прогон, экспорт CSV

Телефон / другие каналы:

- `sample/1845_phone.sm2` — дроссель до 80–99%, разгоны 3840–4779 и 3100–4428
- `sample/1833_phone.sm2` — редкий OBD, сильный набор оборотов
- `sample/0842_map_rpm.sm2` — без педали (MAP/УОЗ/лямбда), только фрагмент по оборотам
