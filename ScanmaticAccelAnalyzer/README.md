# Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Приложение читает **нативный лог Scanmatik `.sm2`** (заголовок SMFS), протокол **OBD-II Livedata**.

## Что делает

1. Загружает `.sm2`.
2. Находит каналы **обороты**, **время**, **педаль или дроссель**.
3. Вырезает только **непрерывный WOT-разгон** (полный газ → рост оборотов).
4. Остальной лог отбрасывается.
5. Строит график ускорения `dRPM/dt` по оборотам и сравнивает прошивки.

## Запуск

`Запуск.bat` или открыть `index.html` в Chrome / Edge.

## Как писать лог в Сканматике

1. Модуль **OBD-II** → текущие данные (Livedata).
2. Обязательно включите:
   - Обороты двигателя (PID 0x0C)
   - Положение педали **или** абсолютное положение дросселя (PID 0x11 / 0x49 / 0x4A)
3. Сохраните отчёт `.sm2` и загрузите в приложение (экспорт CSV не нужен).

## Демо

`sample/demo_obd2.sm2` — реальный фрагмент OBD-II лога.
