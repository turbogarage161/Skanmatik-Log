# Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Приложение читает **нативный лог Scanmatik `.sm2`** (заголовок SMFS), протокол **OBD-II Livedata**. Работает с логами **с ПК и с Android**.

## Что делает

1. Загружает `.sm2` (несколько файлов сразу).
2. Находит каналы **обороты**, **время**, **педаль или дроссель** (что есть в логе).
3. Режет разгоны **ручными ползунками**: обороты 1000–8000 и педаль/дроссель 0–100 (два края у каждого).
4. Строит графики ускорения / полки момента / относительной мощности и сравнивает прошивки.

## Запуск (ПК)

`Запуск.bat` или открыть `index.html` в Chrome / Edge.

## Android (тот же функционал)

Это PWA: тот же интерфейс, ставится на главный экран.

1. Откройте `index.html` в **Chrome** на телефоне (через локальную сеть, GitHub Pages или любой HTTPS/HTTP хост).
2. Меню Chrome → **Добавить на главный экран** (или кнопка «На экран Android», если браузер её показал).
3. Приложение открывается без адресной строки, с теми же фильтрами и графиками.

Логи `.sm2` с телефона Сканматика и с ПК загружаются одинаково.

## Как писать лог в Сканматике

1. Модуль **OBD-II** → текущие данные (Livedata).
2. Включите:
   - Обороты двигателя (PID 0x0C)
   - Положение педали **или** абсолютное положение дросселя (PID 0x11 / 0x49 / 0x4A)
   - По желанию скорость автомобиля
3. Сохраните отчёт `.sm2` и загрузите в приложение (экспорт CSV не нужен).
