# Skanmatik-Log — Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Веб-приложение (ПК + Android PWA) для анализа логов Сканматика `.sm2`: разгоны, фильтр оборотов и педали/дросселя, сравнение прошивок.

## Структура

- **`ScanmaticAccelAnalyzer/`** — приложение (откройте `index.html` или `Запуск.bat`).
- **`*.sm2`** — примеры логов:
  - `260917_0842_Двигатель [7E8] (2).sm2`
  - `260917_1833_Двигатель [7E8].sm2`
  - `260917_1845_Двигатель [7E8].sm2`

## Быстрый старт

1. ПК: `ScanmaticAccelAnalyzer/index.html` в Chrome / Edge.
2. Android: открыть ту же страницу в Chrome → «Добавить на главный экран».
3. Ползунки: обороты **1000–8000** и педаль/дроссель **двумя ручками** с каждого края.
