# Skanmatik-Log — Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Веб-приложение и инструменты для анализа логов Сканматика (`.sm2`) и оценки ускорения двигателя (WOT-разгоны, сравнение прошивок).

## Структура репозитория

- **`ScanmaticAccelAnalyzer/`** — Актуальная версия веб-приложения (HTML / JS / CSS). Позволяет загружать файлы `.sm2` напрямую в браузере, выделять WOT-разгоны и строить графики `dRPM/dt`.
- **`ScanmaticAccelAnalyzer — V1 OK/`** — Стабильная версия 1.
- **`ScanmaticAccelAnalyzer — V2 OK/`** — Стабильная версия 2.
- **`*.sm2`** — Примеры и тестовые дампы логов Сканматика:
  - `260917_0842_Двигатель [7E8] (2).sm2`
  - `260917_1833_Двигатель [7E8].sm2`
  - `260917_1845_Двигатель [7E8].sm2`

## Быстрый старт

Откройте `index.html` внутри папки `ScanmaticAccelAnalyzer` в браузере (Chrome / Edge / Firefox) или запустите `Запуск.bat` (в среде Windows).
