# Skanmatik-Log — Анализатор разгонов Scanmatic (.sm2 / OBD-II)

Веб-приложение для анализа логов Сканматика `.sm2`: участки разгона, сравнение по оборотам.

## Структура

- **`ScanmaticAccelAnalyzer/`** — приложение (`index.html` или `Запуск.bat`).
- **`*.sm2`** — примеры логов.

## Быстрый старт

Откройте `ScanmaticAccelAnalyzer/index.html` в Chrome / Edge.

Фильтры: **обороты начало–конец** (ось графика, любая ширина); **WOT от**. ПК — полка педали у максимума; телефон Scanmatik — короткие пачки и рампа дросселя. Если фильтр пустой, лог всё равно виден.

Примеры логов Сканматика — в `ScanmaticAccelAnalyzer/sample/` (`.sm2` и CSV).
